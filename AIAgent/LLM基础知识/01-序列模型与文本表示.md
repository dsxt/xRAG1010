# 序列模型与文本表示

分类和翻译都要先把句子变成模型能算的数字。这一章只解决这件事：一个词怎么变成向量，词序从哪里来，以及 RNN 翻译里的注意力在算什么。Transformer 的缩放点积在 `02`。

## 1. TF-IDF

一句话先拆成词。中文用分词器（投满分项目用 jieba，标题只留前 30 个词，再用空格接回去）。英文按空格切，标点前补一个空格。

词袋把一篇文档记成「词 → 次数」。文档有长短，次数要先归一化：

```text
TF(t, d) = 词 t 在文档 d 中出现的次数 / 文档 d 的总词数
```

只看词频会把「的、了」抬得很高。逆文档频率惩罚在很多文档里都出现的词：

```text
IDF(t) = log( 语料文档总数 / (包含 t 的文档数 + 1) )
TF-IDF(t, d) = TF(t, d) × IDF(t)
```

分母加 1，是为了某个词在语料里一次都没出现时不要除以 0。一个词在当前文档里常见、在其他文档里少见，TF-IDF 就高，这个词就有区分度。

sklearn 里 `TfidfVectorizer` 在训练集上 `fit_transform`，得到稀疏矩阵。每一项是 `(文档下标, 词下标) = 权重`。停用词表传给 `stop_words`，这些词不进词表。

预测时必须用训练时那一个 vectorizer 做 `transform`。重新 `fit` 会换掉词下标，后面的分类器对不上。

TF-IDF 不看词序。「股价上涨」和「上涨股价」可以变成同一个向量。随机森林接在这个向量后面，适合先做一条便宜的基线，做法在 `04`。

## 2. FastText

FastText 是一个很浅的网络：词嵌入取平均，过一层隐藏层，再映射到类别。它快，是因为结构浅，并且类别很多时用层次 softmax，只沿一条从根到叶子的路径算损失。

浅网络记不住词序，所以用 n-gram 把局部顺序补回来。

- 词内部的子词：`minn`、`maxn` 给出字符 n-gram 的最短和最长长度。实现上先在词两侧加上边界符，再切。`get_subwords` 能看到一个词被拆成了哪些片段。没见过的词可以由子词向量拼出来。
- 词与词之间：`wordNgrams=2` 把相邻词对也当成特征。

中文有两种切法。字级把标题拆成单字再加空格；词级用 jieba。投满分测试集上词级更高，数字在 `04`。

监督数据一行一个样本，标签写在正文前面：

```text
__label__sports 卡 佩 罗 告诉 你 德国 脚 生 猛 的 原因
__label__finance 钢材 期货 首日 两大 品种 成交 165 亿元
```

多标签是同一行前面放多个 `__label__`，训练接口不变。多标签要把 `loss` 设成 `ova`（one-vs-all），每个标签单独过 sigmoid，标签之间互不归一化。预测时 `k` 是最多返回几个标签，`k=-1` 尽量全返回；`threshold` 是概率下限。学习率别一下子开到 1，ova 更容易数值不稳。

负采样只拿一部分负类算损失，训练更快，也让模型见过一些噪声。

调参在课程里是按这个顺序往上加的，每一步都在验证集上看 `(样本数, 精确率, 召回率)`：

| 旋钮 | 作用 |
|---|---|
| 文本清洗 | 英文统一小写，标点前加空格 |
| `epoch` | 多看几遍数据。课程示例从默认拉到 20，精确率提升最明显 |
| `lr` | 学习率。示例里单标签用 1，多标签用 0.1 |
| `wordNgrams` | 相邻词特征，示例用 2 |
| `loss="hs"` | 层次 softmax，类别多时更快 |
| `autotuneValidationFile` + `autotuneDuration` | 在给定秒数内搜超参，验证集只负责挑选，不保证搜到全局最优 |

`dim` 是词向量维度，课程的中文实验用 100。模型用 `save_model` / `load_model` 存取。预测返回 `(标签元组, 概率数组)`，标签字符串里带 `__label__` 前缀，业务侧去掉再对外。

安装若和当前 numpy 2.x 冲突，课程环境退回 `numpy==1.26.4`，或者装 `fasttext-wheel`。

## 3. 用 GRU 做英译法

语料是 `英语\t法语`。清洗：转小写、去掉首尾空白、在 `.!?` 前加空格、其余非字母换成空格。

两种语言各有一张词表。`SOS` 的下标是 0，`EOS` 是 1，真实词从 2 开始编。句子长于 `MAX_LENGTH`（这里是 10）的样本在数据集里被截断。一个 batch 在这份教学代码里是 1 句。

### 编码器

`Embedding → GRU`。`batch_first=True` 时输入是 `[batch, seq, emb]`，输出 `output` 形状相同、最后一维变成 `hidden_size`，`hidden` 仍是 `[num_layers, batch, hidden_size]`。初始隐藏状态全 0。

`output` 的每个时间步是这个英文词看到它左边之后的表示。最后一个时间步的 `hidden` 是整句被压成的一个向量。

### 无注意力的解码器

解码也是 `Embedding → GRU → Linear → LogSoftmax`，词表大小换成法语。每一步只喂一个词，形状 `[1, 1]`。上一步的 `hidden` 传给下一步。线性层之前取的是当前这一步的输出。

整句意思只活在那个传下来的 hidden 里。句子一长，前几个英文词的信息会被后面的词冲掉。

### 带注意力的解码器

这一步开始为「当前要写的那个法文词」单独gather英文侧的信息。

1. 当前输入词做嵌入，得到查询 Q。
2. Q 和上一步隐藏状态 K 在最后一维拼接，过线性层，再 softmax，得到长度等于 `MAX_LENGTH` 的权重。
3. 权重乘编码器各步的输出 V，得到这一步的专属信息包。V 先被拷进一块 `[1, MAX_LENGTH, hidden]` 的零张量，短句后半段保持为 0。
4. Q 和信息包再拼接，线性层压回 `hidden_size`，送进 GRU。
5. GRU 的输出过线性层和 LogSoftmax，得到法语词表上的对数概率。

这里的 Q、K、V 和 `02` 的同名张量不是同一个算法。这里的相似度是「拼接之后的线性层」，V 是编码器每个时间步的隐藏状态。Transformer 里 Q、K、V 都是同一套隐藏状态做三次线性变换，相似度是缩放点积。

### 训练和生成

编码器跑完一句英语之后，解码器从 `SOS` 开始。课程代码以 0.5 的概率走 teacher forcing：下一步输入真实的法语词；否则下一步输入上一步 `topk(1)` 的预测，预测到 `EOS` 就停。损失是每个法语词的负对数似然，按词数平均，再同时更新编码器和解码器。

生成时没有真实法语词，只能走「把预测喂回去」那条路，直到 `EOS` 或达到 `MAX_LENGTH`。

这套模型能翻译短句，计算是按时间步串行的，每个词只能从左往右看。下一步要把「每个词直接看到句中任意一个词」做成一层，并且整句并行，那就是 `02` 的自注意力。
