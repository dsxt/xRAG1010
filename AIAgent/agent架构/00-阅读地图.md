## 2026-11-20 这几条已经定下来

写新内容时沿用这些口径，不要从旧稿里把它们写回去：

- 接入网关和模型网关用 Go。沙箱和热点计算用 Rust。编排、RAG、评测用 Python。页面和 CLI 用 TypeScript。
- MCP 远程传输是 Streamable HTTP。2026-07-28 起核心协议不再依赖粘性会话。旧的 HTTP+SSE 双端点不再作为新接入方式。
- AutoGen 处于维护状态。新项目的微软生态编排用 Microsoft Agent Framework。对照实验可以仍用 CrewAI，不把已停更的框架写成主路径。
- vLLM V1 抢占后重算，不再做 GPU 与 CPU 之间的 KV 交换。
- 策略规则只有一份。写操作在策略不可用时失败关闭。幂等的最后一道是业务表唯一约束。
- 任务状态只有一套小写值，见 `01` 第 4.1 节。阶段只写 Trace。对外错误码以 `01` 第 0.2 节为准。改这三项或 `TaskSpec` 时，先改 `05-架构契约.md` 文首清单，再改 `01`、`03`、`04`。
- 生成合成内容标识打在用户可见的出口。审计原文不能由业务进程改写。
- 多 Agent 先有单 Agent 基线。图 RAG 和多模态先有混合检索基线。
