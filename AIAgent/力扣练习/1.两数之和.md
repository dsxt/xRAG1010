# 两数之和
给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target  的那 两个 整数，并返回它们的数组下标。
你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。
你可以按任意顺序返回答案。

---

# 暴力解法 O(n²)

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):        # j 从 i+1 开始，避免重复 & 避免同元素
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []
```

时间 O(n²)，空间 O(1)。n ≤ 10⁴ 时能过，但不是最优。

---

# 推荐解法：哈希表 O(n)

**核心思想**：遍历一遍，对每个 `nums[i]`，只需检查之前是否出现过 `target - nums[i]`。

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}                            # 值 -> 下标
        for i, num in enumerate(nums):
            need = target - num
            if need in seen:
                return [seen[need], i]
            seen[num] = i
        return []
```

**为什么 O(n)？** 每个元素只入表一次、查表一次，`dict` 的查找是 O(1)（平均）。

**为什么能处理 `[3,3]` 这种重复元素？** 因为先查 `need` 再存入 `num`，第二个 3 查表时能匹配到第一个 3 的下标，而不会自己匹配自己（自己还没存进去）。
