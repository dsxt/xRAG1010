这道题用 **双指针** 最合适：左右各一个指针，每次移动较矮的那一侧。

### 思路

容器面积由两个因素决定：

```text
面积 = min(height[left], height[right]) * (right - left)
```

- 宽度是 `right - left`
- 高度取决于较矮的那条线

如果移动较高的那一侧，宽度变小，高度最多还是原来较矮的那条线，面积只会更小。  
所以应该移动较矮的那一侧，才有机会找到更高的线，从而增大面积。

### Python 代码

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left = 0
        right = len(height) - 1
        max_area = 0

        while left < right:
            width = right - left
            if height[left] < height[right]:
                area = height[left] * width
                left += 1
            else:
                area = height[right] * width
                right -= 1
            max_area = max(max_area, area)

        return max_area
```

### 复杂度

- 时间复杂度：O(n)，左右指针一共最多移动 n 次
- 空间复杂度：O(1)
