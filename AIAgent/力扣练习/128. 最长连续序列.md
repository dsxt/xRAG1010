这道题的关键是做到 **O(n)**，所以不能先排序。可以用 **集合 + 只从序列起点开始扩展**。

### 思路

1. 把 `nums` 放进 `set`，去重并支持 O(1) 查找。
2. 遍历每个数 `num`：
   - 如果 `num - 1` 也在集合里，说明 `num` 不是序列起点，跳过。
   - 如果 `num - 1` 不在集合里，说明 `num` 可能是一个连续序列的起点，就从 `num` 开始往后找 `num + 1, num + 2, ...`。
3. 记录最长长度。

虽然里面有 `while`，但每个数最多被访问一次，所以整体仍是 **O(n)**。

### Python 代码

```python
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        num_set = set(nums)
        longest = 0

        for num in num_set:
            # 只从序列起点开始
            if num - 1 not in num_set:
                current = num
                length = 1

                while current + 1 in num_set:
                    current += 1
                    length += 1

                longest = max(longest, length)

        return longest
```
