这道题用 **双指针** 最合适：一个指针负责找非零元素，另一个指针负责记录非零元素应该放的位置。

### Python 代码

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1

        for i in range(slow, len(nums)):
            nums[i] = 0
```


### 复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(1)，原地修改

### 进阶：尽量减少操作次数

如果想减少赋值次数，可以改成“遇到非零且位置不同时才交换”：

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                if fast != slow:
                    nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```
