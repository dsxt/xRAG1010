# Agent 应用开发：面试与学习

口径：**2026-11-20**，与 `agent架构/03-语言分工.md`、`00-阅读地图.md` 一致。

四层分工：TypeScript 写交互入口，Python 写编排与策略，Go 写接入网关和模型网关，Rust 写沙箱与热点计算。Star 是约数。框架和教程多数来自当天 GitHub API；协议、网关、隔离运行时来自当天仓库页（API 限流）。LlamaIndex 约 53k 来自当天公开框架榜，未单仓复核。

## 怎么看时效

当天核对过 Star、是否还在维护、链接是不是主仓库。另有三条钟，不要合成一个「该学的框架榜」：

- **结构**（循环、状态、工具、评测）：`hello-agents`、PocketFlow 还能用比较久。
- **框架 API、SDK 主版本**：按月对官方文档。MCP 以 [规范仓库](https://github.com/modelcontextprotocol/modelcontextprotocol) 为准。2026-07-28 起远程传输是 Streamable HTTP，新接入不再用旧的 HTTP+SSE 双端点。TypeScript SDK 的主线已是 v2。
- **模型默认会写出的代码、岗位上「现在怎么做」**：按周过期。编程 Agent 的训练语料偏旧，交互层用技能包把当前写法注进上下文。

图里两个地址以主仓库为准：`jtrocky/ai-agent-interview-guide` 是 fork；`zgd716/AgentGuide` 已指向 `adongwanai/AgentGuide`。

## 隔离层 · Rust

启用条件：出现高风险代码或命令执行，或热点计算已经实测需要从 Python 下沉。没有这两类负载时，用独立容器（非 root、只读根文件系统、出网白名单、内存和 CPU 限额），不把第四种语言带进值班。
