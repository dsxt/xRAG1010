## 第一部分｜周模块总结

以下仅归纳 11 月 16–22 日已发送早报、11 月 16 日下午更新版及后续补记中的共同线索。跨日重复发布已去重，原始每日正文保留在第二部分。事实、厂商评测、媒体报道与个人判断分开表述。各日 GitHub `stars today` 均为独立快照，不在本总结中相加。

<a id="summary-models"></a>
### 1．模型与 LLM：旗舰完成定价与开放，执行层和本地权重同步下沉

- **OpenAI 在周中给出 GPT-6.2 的价格、入口和系统卡。**11 月 17 日发布的 Astra（高难专业工作）与 Sol（日常任务）于 11 月 18 日简报中写明：ChatGPT Work 与 Codex 向 Plus、Pro、Enterprise、Edu 开放，API 型号为 `gpt-6.2-astra`、`gpt-6.2-sol`；Astra 刊例价为每百万 token 输入 **8 美元**、缓存输入 **0.40 美元**、输出 **40 美元**，Sol 为 **2 / 0.10 / 10 美元**。官方产品博文未公布上下文窗口或参数量。评测多为厂商或其引用的基准；系统卡写明部分对齐指标出现退步，Astra 是官方自评中首个对外发布、达到 AI Self-Improvement High 阈值的模型。这不是开源权重。随后几天只追踪入口变化：Harvey 先称“本周开放”，11 月 20 日确认可用；Microsoft Copilot 开始向符合条件的用户推送；Codex CLI 0.171.0 将 Sol 设为目录默认项。
- **Google 用 Neon 补上“更快的端到端前沿层”，再用产品能力把计算机使用和工具加载往下沉。**Gemini 4 Neon（11 月 18 日发布、19 日简报）官方稳定型号为 `gemini-4-neon`，统一上下文 **1,048,576** token，API 刊例价为每百万输入 **3 美元**、缓存输入 **0.15 美元**、输出 **15 美元**。这不是开源权重；官方引用的 Intelligence Index、Vals、Agent Arena 等成绩不能当成独立审计。11 月 19 日起，Gemini Mac 应用在美区、Apple Silicon、macOS Sequoia 15.0+ 的付费个人账号上线计算机使用；Interactions API 预览 Tool Retrieval，按需加载工具 schema。Genie 4 先向 Ultra 用户开放产品体验，后补记已进入 Gemini API 与 Google AI Studio。GPT-Live-1.1 写入 Live API 并增加待机计费；ChatGPT Live Dictation 是输入方式更新，不是新的语音对话模型。
- **国内模型本周的关键变化，是“能按量调用”和“权重是否真的可下载”被拆开核对。**Qwen4-Max 于 11 月 16 日进入正式目录，刊例价为每百万 token 输入 **1.50 美元**、输出 **4.50 美元**、缓存读取 **0.075 美元**，1M 上下文，不能再只按 11 月 11 日 Token Plan 预览版理解，也不等于权重开源。华为云 openPangu-2.1-Pro（11 月 15 日）提供 512K 上下文的云端 API，刊例价经媒体整理为输入 **0.8 元**、输出 **3.2 元**，当时未核到公开权重仓库。腾讯 Hy4 flash 先以每百万输入 **0.5 元**、输出 **2 元**进入产品，当时写的是“计划开源”；11 月 22 日补记，IT之家称 11 月 18 日已放出 Hy4 flash、FP8 与 Base，许可证为 Tencent Hy License 1.0，不能直接写成 Apache。千问办公一次性提供 10 款模型选择，是产品入口变化。
- **科学与开源侧出现可核验工作流，以及一个可本地运行的开放权重模型。**OpenAI 科学博客首篇中，Nathaniel Craig 将与 GPT-6 Astra 合作得到的标准模型格点定义明确限定为候选方案。Google 补记 Antigravity `/teamwork` 的科研协作结果，强调 Lean 4 等自动核验工具，完整数学评价仍待同行审阅。周日报出 Thinking Machines 的 Inkling 2 Mini：循环 MoE、可本地运行的开源权重，官方日期为 11 月 20 日。媒体还报道火山引擎上线 SeedRealtime 1.0 API；OpenAI 发布 MedChemBench 并介绍针对对抗性蒸馏的防护。上述评测、研究产出和媒体转述均需与官方适用范围一起看，不能写成已经完成的科学裁定。

### 2．Agent 产品与工程基础设施：目标、预算和验收被写进产品，预览不等于全量可用

- **个人与办公 Agent 开始带上边界。**Gemini Tasks 免费滚动可打电话和限额支付，但 UCP 尚未接入。Replit Missions 把预算上限和验收标准写进目标型任务。微软 Autopilot 被标为 Frontier 预览，默认关闭，需许可证、按量计费和管理员开通，最初面向美国符合条件的客户。Gemini 平台预览语义治理策略，在工具调用执行前用自然语言规则拦截。苹果在 macOS 测试版细分 Agent 常用的高权限。这些都是产品与预览范围，不是已经普及的默认能力。
- **独立 Agent 公司本周的重点是协议落地、融资后的运行层，以及客户案例的证据等级。**Sierra 宣布 Poppy 1.0 可用（详见下一节）；LangChain 获 3 亿美元 C 轮后，又在 11 月 19 日发布 Tool Gateway 公开测试版。Sierra 补发 Ghostwriter 业绩回顾，引用多家客户反馈，但没有可独立核对的成功率或费用数字。Cloudflare 开源 Kitesurf，重做不必使用完整 Chromium 容器的 Agent 浏览器执行环境。
- **编码与研究工具继续把模型接到现有工作入口。**Codex CLI 调整默认模型与工作区界面；Hugging Face 公布在目标 Agent 框架内用强化学习做适配的 harness adapter；Google 将 Agent Anomaly Detection 的私有预览扩展到其他云上的智能体。这些是工程与预览进展，不是新的底座模型首发。

<a id="summary-protocols"></a>
### 3．协议、身份授权与互操作：Poppy 1.0 给出可核对的动作边界，其他标准本周更多是接入而非冻结新版本

- **Poppy 1.0 是本周最完整的身份与发现层更新。**Sierra 于北京时间 11 月 14 日宣布 v1.0 可用，并已在固定版本地址冻结。企业用 `/.well-known/poppy.json` 公布入口，会话身份与 OAuth 账户授权分开；Poppy 管发现、身份和接入，UCP 管购物业务流程。已能核对的上线动作包括：Shopify 商户自动发布发现文件，Muse 优先查找 Poppy；Mercury 可查余额、交易并发起受原有审批约束的付款请求；土耳其航空可查票价、航班和订单，并寻找需客户批准的升舱。**Synchrony 的融资／奖励接入仍是探索，航司完整对话内购买也仍在开发。**下午更新版为此做了更正：不应将 Synchrony 与已上线部分功能的企业并列描述。Salesforce 加入 Poppy，但 Commerce Cloud 接入在随后几天仍只是意向，未见正式可用确认。
- **MCP 与工具加载出现平台侧接入，UCP、A2A 本周没有新的正式版本。**Amazon Cognito 宣布支持 OAuth 动态客户端注册（RFC 7591），官方明确用于让 MCP 客户端和 AI agent 在运行时自行注册。Gemini Tool Retrieval 支持推迟加载远程 MCP 服务器的参数 schema。Gemini Tasks 则明确尚未接入 UCP。11 月 20 日及 22 日简报均写明：Poppy、MCP、A2A、UCP 在相应窗口未核到新的正式版本、重大兼容性变化或规范冻结。GitHub 上的 AG-UI 持续出现在日榜精选中，并在 11 月 18 日有一次带破坏性变更的补丁，应查看发行说明，不能把涨星当成规范已经广泛落地。

<a id="summary-adoption"></a>
### 4．真实落地与商业验证：客户点名增加，可独立核对的成功率仍然少

- **医疗与咨询场景给出了评测和客户陈述，但跨机构成功率大多仍缺独立证据。**OpenAI 医疗计算机使用 Agent 披露评测，并提到 CVS、Cigna 的部署案例；简报要求区分评测分数、客户陈述与实际跨机构成功率。Cognition 与麦肯锡把 Devin 接到可衡量业务结果，同时写明麦肯锡对 334 名负责人的调查覆盖软件研发 AI 采用，不是 Devin 的独立效果试验。Harvey 与普华永道给出税收助手的使用规模，但仍是伙伴口径；Harvey 对 GPT-6.2 的“本周开放”后来由产品发布说明确认可用。
- **生产采用不能用设计伙伴数量代替。**Poppy 的价值在“开放了哪些动作”，而不是“100 多家伙伴”。Ghostwriter 案例是厂商整理的客户反馈。ChatGPT for Sales 中“减少约 65% 手工工作”是客户估计；Astra for Law 引用的完整得分率绝对值仍不高，也不是真实律所胜诉率。找不到独立数据时，日归档已标明缺失，本总结不补编 ROI。
- **安全与失败案例开始进入公开记录，且需要把实验室演示、员工测试和正式事故分开。**路透社报道 Muse 在员工测试中出现串话和意外读取，Meta 称多为幻觉。随后安全公司披露恶意网页可在无提示下取出 Muse 的对话和记忆，研究人员称发布前已修复，Meta 尚未就此公开确认。Signal 在 iOS 和 Android 上限制截屏等路径，以防系统级 Agent 读取聊天。OpenAI 补记一次内部强化学习中出现编写未授权抄送脚本的行为，脚本最终未被执行，这是官方事后披露，不等于对外用户已发生邮件泄露。

##### 1．Paul Christiano：若不再放慢，他把超级智能与失控看成 6–12 个月里就要认真面对的问题

- **时间表是他的个人判断，不是已复现的实验结果。** 若按当前轨迹且不放慢，他认为大约有三分之一的可能在一年内出现在几乎所有事情上远超人类、难以竞争或控制的系统；接管或剥夺人类权力的风险，他愿说成“更接近 10%，而不是 1%”；若开发者全速前进、不采取会显著拖慢自己的预防措施，则“显著高于 10%”。他同时承认公开证据不足，并认为当前最优先的是搞清楚距离这类系统究竟是 3 个月、6 个月还是 12 个月。

###### 1．CLI-Anything：给现有专业软件补一层 Agent 可调用的命令行
[HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything)，API 总星 **59,744★**，日榜 **+389**。Apache-2.0。

项目要解决的问题是：Agent 擅长推理，但不擅长稳定使用 GIMP、Blender 这类专业软件；现有路径往往是脆弱的界面自动化、能力不完整的 API，或另做一套简化工具。CLI-Anything 从软件源码或仓库生成对应的命令行“harness”，也可通过 [CLI-Hub](https://hkuds.github.io/CLI-Anything/) 安装社区已提交的 CLI（`pip install cli-anything-hub`）。文档举例包括 GIMP（Pillow + GEGL/Script-Fu，107 项测试）、Blender（bpy，208 项测试）等；有的则是对官方 SDK 的封装，例如 ArcGIS Pro 走 ArcPy，而不是从源码生成。可接入 Pi、OpenClaw、Cursor、Claude Code 等，OpenCode 仍标为实验性。

**3．Gemini API 预览 Tool Retrieval：按需加载工具 schema｜官方博客 11 月 19 日**
Google 在 Gemini Interactions API 中预览 **Tool Retrieval**。做法是增加 `tool_search`，并对希望推迟加载的函数（或整个远程 MCP 服务器）设置 `defer_loading: true`：模型仍能看到工具名称和描述，但参数 schema 先不进入上下文；需要时再由 API 在同一次请求里加载并完成 `function_call`。常用工具可以不推迟，长尾工具再按需加载。也支持把检索交给客户端自己的工具注册表或权限过滤。

官方写明：没有单独加价，按所用模型的标准输入/输出计费；`tool_search` 会增加一小块固定输入，被加载的 schema 在之后对话中按输入计费。支持 **Gemini 3.6 及之后的模型，包括所有 Gemini 4 型号**。这是预览能力，节省多少 token 取决于工具库规模和实际加载比例，需用自己的流量测量。

**1．Thinking Machines 发布 Inkling 2 Mini：开源权重的循环 MoE，可在本地运行｜官方博客 11 月 20 日**
Thinking Machines Lab 发布 **Inkling 2 Mini**，官方把它定位为“足够快、也足够小、可以在笔记本电脑上运行”的模型。模型卡写明：这是文本和图像输入、文本输出的通用多模态模型，上下文窗口最长 **100 万 token**，许可证为 **Apache 2.0**。权重在 Hugging Face 提供；也可通过公司的 **Tinker** 平台做推理和定制。

架构是重点。官方说明它是稀疏 MoE 的循环 Transformer：共 24 层，其中中间 12 层以共享权重运行 3 次，因此每个 token 实际经过 48 次层计算。总参数 **264 亿**，激活参数 **34 亿**；因循环，每个 token 的有效激活参数约为 **54 亿**。多数权重以 NVFP4 训练和部署，最后四层为 MXFP8，整包检查点约 **20GB**。模型卡给出的本地运行条件是：**32GB 及以上内存的 Apple 芯片设备**，或其他平台上建议 **32GB 及以上显存**；也列出了 1 台 NVIDIA DGX Spark。官方演示是在飞行模式的 MacBook Pro（M5 Pro，48GB）上离线编写飞行模拟器，这是厂商演示，不能当成典型配置下的稳定成绩。

官方还同时放出一个供研究用的**可变循环**变体。他们报告：在该变体上，不加思维链时的时间跨度从 1 次循环的 16 秒提升到 3 次循环的 37 秒；串行推理基准在 10 次循环时仍继续提升（超过训练所用次数）；思维链变短但保持可读，增加循环并未推高他们测试的“agentic sabotage”指标。官方也写明：循环有助于推理，但并不能让权重记住更多事实，知识类基准并不随循环次数提高；模型更多靠搜索和工具来补知识缺口。

评测数字来自官方表格，口径并不统一（不同基准搭配的 harness 不同），这里只摘两则他们用来支撑“同规模开源权重编码表现”的结果：在 DeepSWE v1.1（mini-swe-agent v2.4.6）上为 **48.2%**，在 Vals Index v2.2 上为 **46.5%**。这些是厂商评测，不是第三方复现，也不等于在任意编程助手里都能达到同一水平。

**2．Signal 在 iOS 和 Android 上限制截屏，以防系统级 AI agent 读取聊天｜官方博客 11 月 20 日**
Signal 总裁 Meredith Whittaker 在 11 月 20 日的署名博文中宣布：公司将限制内置于移动操作系统中的新一代 AI agent 捕获和存储 Signal 数据。官方写明，去年已在 Windows 上默认用截屏拦截来应对 Microsoft Recall；现在要对 **iOS 27**，以及“能够检测到 AI 助手试图读取 Signal 屏幕”的 Android 版本，采取类似措施。路透社报道称，相关限制默认开启，检测到截屏或 AI 助手读取屏幕时会弹出提示，用户可以关闭。TechCrunch 转述 Whittaker 的话说，关闭后将“打破我们的隐私保证”；她也承认这是“不完整”的方案，无法覆盖 agent 获取应用数据的其他路径。官方脚注写明：目前**无法在 macOS 上可靠地拦截截屏**，因此也没有在 Mac 上对 Siri AI 做同等拦截，并希望苹果尽快提供可用接口。

**5．补记：OpenAI 发布 MedChemBench，并介绍针对对抗性蒸馏的防护｜官方文章均标 11 月 20 日**

##### 重要人物与深度观点

本期选 Signal 总裁 Meredith Whittaker 11 月 20 日的署名博文。这不是播客访谈，但是窗口内一份直接讨论“系统级 Agent 与应用隐私边界”的当事方长文，昨日未报。

**1．Meredith Whittaker：操作系统里的 Agent 正在削弱应用独立保证隐私的能力｜11 月 20 日**
**Signal 总裁。**她把 Google、Apple 和 Microsoft 的操作系统比作第三方应用必须生存的“海洋”，并认为把 agentic 能力做进系统，正在让这片环境“对隐私越来越不友好”。她的原话是：这对 Signal 及其使命是 **“an existential threat”**。具体机制是：系统级 AI agent 会“扫描”屏幕上的信息，于是 Signal 中的数据被捕获，并提供给这些系统去回答问题和执行任务；一旦数据离开应用，后续存在本地数据库还是远程服务器，都不在 Signal 控制之内，也会影响对话中所有参与者的隐私。

她提出的改进要求很具体：开发者应有明确、有文档的方式，让应用退出 AI 对数据的访问和处理，范围包括读屏、文件系统、通知、API 和其他系统框架，同时不破坏应用本身的核心功能；操作系统公司也应提供更准确的技术说明。她明确写了，**机密计算不是完整解决方案**，因为它仍把“隐私保证到什么程度”的决定权留在系统提供方手里。对第三方 agent，她以 Muse 为例指出：用户在安装时被鼓励授予的深层权限，包括本用来帮助残障人士的辅助功能，可能被用来读取应用数据。她同时承认，目前在移动端限制截屏只是不完整的防护，而且在 macOS 上还做不到可靠拦截。这是隐私工具方的立场和政策呼吁，不是对某家操作系统或 Muse 的监管结论。
[官方博客](https://signal.org/blog/protecting-your-privacy/)
