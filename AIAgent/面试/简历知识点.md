  谷子昂一作，2024 preprint。作者 ZiAng Gu, Zhiyuan Ren, Feng Liu, Tianlong Chen, Xiaoming Liu。作者页 https://zianggu1.github.io/physibuilder.html ，没有对上 arXiv 编号。多物体 text-to-3D 若直接优化一张渲染图，同一物体会在不同视角里换身份（Janus）。ScenePlannerLLM 先产出可检查的场景先验：对象、粗体积基元、支撑关系；多次采样做 self-consistency，再用碰撞和重力把违规布局打回模型。SceneConstructor 为每个物体建局部 NeRF，平移旋转只改布局变换。物理检查发生在 NeRF 优化之前，查的是穿模和悬空。

## Agent 运行时

简历里反复出现的是循环、状态、恢复和轨迹，不是某一个框架名。

- **Harness**  
  模型调用、上下文组装、工具执行、权限、子 Agent、事件日志拆开。王艺辉用 Runtime–Executor–SessionPool 承载多条生产链路。孟祥龙的 Quilin 拆运行循环、流式调用、工具调度、会话、检查点、钩子、子 Agent 生命周期。冯威把 Agent、Skill、Tool Runtime 分开，用 Task / TaskStep / Run / ExecutionEvent 记 Trace。Etcetera 的桌面工作台把同一次运行写成只追加事件，崩溃后审批可续。Ahamed 写过带合规检查的编排 harness。
- **状态图与检查点**  
  LangGraph StateGraph、thread、checkpoint、interrupt。李鹏斌的旅行助手是 Ask / Search / Research / Update 多分支。郭靖的工作流有条件、循环、变量传递和执行引擎。会话状态要能跨请求恢复（冯威、小猿教育段；蔡杰超用 Redis 做断线进度）。
- **Plan / Execute，以及重规划**  
  张利娜：Classifier / Extractor、Context Builder、LLM 规划、Replanner 三策略。Etcetera 的编码 Agent 分 Plan / Exec，另有 Compaction 和 Build 子 Agent。谷子昂的专利检索是生成 query pack、检索、按 trace 改 helper。
- **长任务**  
  租约、心跳、步骤持久化、SSE 断线回放、强杀后续跑、人工审批后从暂停处继续（Etcetera）。异步研究任务、缓存指纹、断点续跑（李鹏斌）。离线任务长程调度、自动重试、质量校验（王艺辉）。Cron / 定时 Agent（戴雨欣、谷子昂、孟祥龙的经营日报）。
- **事件溯源与 Run Inspector**  
  每次运行、工具调用、审批落成时间线，方便复盘（Etcetera、孟祥龙、冯威）。
- **失败恢复**  
  按失败类型重试、压缩上下文、人工接管、反射重试（李鹏斌 AutoPentest）。工具或外部依赖不可用时降级：Chroma 不可用改关键词（李鹏斌），无 LLM key 走本地确定性构建（梁慧），Redis 不可用有降级路径（李鹏斌）。模型输出缺字段时，把校验错误回给模型再修一次；业务拒绝（无权限、库存不足）把原因回给模型改计划，不按同一参数盲重试。写操作重试用幂等键取回上次结果。

各站挡住的失败：

| 站 | 挡住的失败 | 简历里的做法 |
|---|---|---|
| 意图或计划 | 工具全塞进上下文，或计划一次写死 | 张利娜先分类再按组披露工具；计划失败走 Replanner |
| 状态 | 进程重启后不知道做到哪一步 | LangGraph checkpoint；Etcetera 只追加事件；步骤逐条落库。检查点写在副作用提交之后，未完成的调用标成 in-flight |
| 工具执行 | 参数错、超时、重复写 | Registry 里做超时、配额、幂等；写操作先出确认卡 |

| 压缩 | 长任务把窗口撑爆 | Compaction；对话摘要；多轮压成一条独立请求 |
| 评测门 | 改了 prompt 无法知道是否变差 | 回归集通过才灰度；Bad Case 进沙箱再进 PR |

## RAG 与检索

- **混合召回**  
  顺序是：查询改写 → 硬过滤 → BM25 与稠密向量各出一份排序 → RRF 融合 → 交叉编码器或 ColBERT 只重排前几十条。BM25 吃专有名词和编号，稠密向量吃改写后的语义。两路分数单位不同，不能直接相加。RRF（Cormack, Clarke, Buettcher，SIGIR 2009）只用名次：某一路排第 r 名得 1/(k+r)，k 常用 60，再对所有路求和。交叉编码器把 query 和文档拼在一起打分，比双塔准，也更贵。ColBERT（Khattab, Zaharia，SIGIR 2020）是晚交互：两边各留一串 token 向量，每个 query token 在文档里找最大内积再求和。出现在刘稔远、Sanjay（交叉编码器加 ColBERT）、冯威（BGE-M3 + BGE-Reranker）、王长玉（Elasticsearch 关键词 + Milvus）、张利娜（BM25 + Milvus，再加一路业务数据）、孟祥龙（Milvus 金标准样例）、郭靖（多策略检索）。Etcetera 还加了 FTS、标题匹配、标签倒排。
- **BGE-M3 与 BGE-Reranker**  
  BGE-M3 对应 Chen 等，*M3-Embedding*，ACL Findings 2024，arXiv:2402.03216。一个编码器同时出三路：CLS 内积（稠密）、token 权重乘积之和（词法）、整段 token 的晚交互（算法同 ColBERT）。训练用三路分数之和做自蒸馏。输入约 8192 token，覆盖 100 多种语言。冯威写的 BGE-Reranker 是另一个交叉编码器，用在重排那一步。
- **查询改写与过滤**  
  改写补全指代和省略（冯威、王长玉、Etcetera）。刘稔远把改写放在规划模型外面：规则状态机、近期状态和会话内 BM25，把多轮压成一条独立请求。硬过滤在打分之前做，按目的地、权限、租户、语种丢掉不可能的片段。李鹏斌按目的地过滤，消融里跨目的地污染从 17 条降到 0。无权限文档不应进入候选。刘稔远用领域原型向量做 Domain 划分。
- **证据与引用**  
  回答要落到已读页、页码或条款（Etcetera、王艺辉的原文导航、王长玉的章节和时间点）。谷子昂 citation preflight：核引用片段是否支撑主张，不够就重搜、换来源或改结论。Sanjay 在 schema 里强制每条发现引用文档区间或条款 ID。李鹏斌做引用一致性，并区分证据够不够：不够才补查一次，有界，不无限循环。
- **切片与增量**  
  按章节切、按内容哈希增量嵌入（冯威、李鹏斌的 Report 切块）。结构化上下文先生产，再供生成和对话用（王艺辉：条款、OCR、产品事实）。

## 评测与可观测

- **检索指标**  
  Recall@K 是相关文档里有多少落在前 K，K 变了不能直接比。MRR 是每条查询取第一个相关结果的名次 r，得 1/r 再平均；没有命中的查询贡献 0，不能从分母里拿掉。nDCG 把相关度分档，名次越靠后折扣越大，再除以理想排序的分数。引用命中是答案里的引用能对上这次读过的片段；Recall 高仍然可能引用错页。李鹏斌用历史 Trace 和人工 golden set，对检索参数、重排和 prompt 做 A/B，一次只改一项。刘稔远报的是工具全召回和端到端工具链精确匹配。Sanjay 的 IndicRAG 用多语种 golden set，并单测答不了和假前提：那 6 条的指标是拒绝或纠正。评测题如果和文档同一套措辞，稠密检索会显得特别强。
- **Agent 任务评测**  
  李鹏斌写的 tau3-style，对应 τ-bench（Yao, Shinn, Razavi, Narasimhan，arXiv:2406.12045，后为 ICLR 2025）及其后续 τ²、τ³。τ³ 修了旧任务并加了新领域。简历用的是这种评测方式：模拟用户、领域 API、一份策略；数据库只能经工具读写；用户模拟器看不到工具轨迹。奖励是 0 或 1，终态数据库和必须回复的信息都要对。pass^k 要求同一任务独立跑 k 次全部成功。单次成功率 0.8 时，pass^4 大约只有 0.41。他的 grader 分 case、turn、意图、工具动作、高风险动作，fixture 和 real 分开报。Yadeesh：固定任务集、held-out、同一配置、工具调用上限、固定 harness commit、每轮清空状态；四层评分是终态、相对初始状态的 diff、禁止动作、LLM judge（和人的一致率 88%）。开发集上的涨点要在 held-out 上再看。
- **生成质量与元评测**  
  王艺辉：完整度、忠实度、逻辑、合规。RCR 是同一输出、同一量表打两次的一致率，低说明评测本身不稳。ESF 是评测员在 checkpoint 上能不能复现专家分数，低说明自动分还不能代替人。李鹏斌用 Shadow Grader 看忠实度。Sanjay AgentOps 看 faithfulness、检索相关性、幻觉，以及 prompt A/B 的成本、延迟、成功率。谷子昂用 answer-blind eval：评分时不把标准答案全文给评测模型，按 rubric 和轨迹打。评委模型和被评模型要分开。
- **回归与发布**  
  改检索参数、rerank 或 prompt 都要能回归（李鹏斌、孟祥龙的 SBS 盲测）。Etcetera 规则版本先过回归集再灰度、晋升或回滚。王艺辉的业务闭环是 Bad Case、归因、沙箱、PR、受控发布、线上反馈。
- **Trace 与成本**  
  Langfuse 做到 token 级（蔡杰超、也是这批简历里网关可观测的主要例子）。LangSmith + Datadog 管 prompt 版本、trace、P95（Aman）。OpenTelemetry + Prometheus 看 token、耗时、成功率（李鹏斌）。Sanjay 用 12 张 trace 表拆模型和阶段延迟。蔡杰超把网关日志打成多团队成本日报。
- **延迟口径**  
  首 token、首包音频、检索延迟、重排延迟要分开写。Aman 用便宜模型做简单任务、贵模型做难推理。刘稔远用查询向量和难度把请求分到不同规模模型。张利娜按复杂度和语种选模。

## 训练、微调与推理

简历里和 Agent 帖在一起的模型工作，深度差很多。应用岗常见的是路由、微调和部署，不是预训练。

- **微调**  
  LoRA（Hu 等，ICLR 2022）不改原权重 W，旁边加低秩支路，输出是 Wx + BAx。A 是 r×d，B 是 d×r，r 远小于 d，常加在注意力的 Q、V 上。换任务就换这一对小矩阵。QLoRA（Dettmers 等）先把基座量化再加 LoRA。P-Tuning 在输入侧加可训练的连续向量，ChatGLM 早期常用。邓乾把 LoRA 和 P-Tuning 并列，说明教学 RAG 试过两种改法；上线时要选定一种。使用处：冯威的 ChatGLM3、邓乾的 ChatGLM-6B、Ahamed 的临床逻辑矛盾分类、刘稔远的意图分类和工具链、谷子昂的服装正反面一致性。
- **SFT 与 DPO**  
  SFT 用正确轨迹做监督。同风格把数据从 9K 加到 54K 没有稳定收益，换成跨风格轨迹才涨，缺的是覆盖。DPO（Rafailov 等，NeurIPS 2023）用成对偏好直接训策略：提高选中答案相对参考模型的对数概率，压低拒绝答案相对参考模型的对数概率，温差由 β 缩放。β 大，离参考模型更近；β 小，学得更猛。刘稔远先 SFT 到 85.7%，再从父模型 8309 个真实错误里做 4000 对偏好，比较多种 DPO/RPO 配方。他写的 RPO 在公开文献里常指 Relative Preference Optimization，具体实现以他的实验记录为准。偏好对要来自这个模型真实犯过的错。分类准确率上去之后，工具链评测要再跑一遍。
- **小模型分流**  
  意图分类可以用小模型（刘稔远 Qwen3-0.6B 对比 1.7B）。规则能做的不要交给 LLM：张利娜 14 路意图里 13 路是规则；冯威直播回复是关键词优先、LLM 兜底。
- **推理服务**  
  vLLM 与 MLX 按硬件切换（Bingo）。昇腾上比较 vLLM Ascend 和 SGLang 的 Prefill / Decode（刘稔远，DeepSeek V4）。端侧用 ncnn 跑语音识别（邓乾）。数字人链路拆环境和 GPU 锁：HeyGem、IndexTTS2、ONNX Runtime、单 Worker（冯威）。
- **算子与国产卡**  
  刘稔远把 kernel agent 从 NVIDIA 流程迁到昇腾 910B/910C：检索、生成、编译、精度、性能、保留或回退。用 msprof 看计算、访存、同步和负载。融合反向算子改分块和片上缓存，并用余弦相似度和相对误差守精度。
- **传统模型仍出现在业务里**  
  LightGBM 做仿真分桶（张利娜）。VGG16 做成衣图像检索（冯威）。YOLOv8 / ONNX 做缺陷和半导体质检（Bingo）。M2M100 做工序翻译（冯威）。GAN、AutoEncoder 做流量合成和入侵检测（李鹏斌）。ViT 做卫星图分割（李鹏斌）和皮肤镜分类（Yadeesh，HAM10000，CutMix / MixUp，Grad-CAM / LIME）。

## 安全、权限与人工确认

- **人确认写操作**  
  确认是一次中断：状态写成等待，人确认后用同一个 thread 从中断处继续。确认卡和预览指纹卡在服务端，确认时的正文哈希必须等于真正发出去的内容（Etcetera）。只在界面上弹确定，模型仍可能在按钮之后改参数。高风险工具：采购、调价、发券、对外邮件、目录上线（孟祥龙、谷子昂、戴雨欣）。临床和交班摘要交给人复核（谷子昂、Ahamed）。戴雨欣允许生成 SQL，库侧只接受 SELECT。
- **授权范围**  
  李鹏斌要求写明目标资产、允许动作、目的和期限，过期不能继续。渗透测试用 CIDR 校验、危险命令拦截、Reviewer、Docker 沙盒。梁慧对可观测自愈限定白名单命令。
- **注入与引用**  
  外部证据当不可执行数据，做风险规则和引用回溯（李鹏斌）。机密路径过滤，落库前脱敏（Etcetera）。SSRF、DNS rebinding、AST 白名单（梁慧、Sanjay）。
- **身份与数据权限**  
  OIDC、RBAC、RLS（Etcetera）。题库五角色状态机（蔡杰超）。多租户或按工号隔离容器（这批简历里的编码 Agent 场景）。JWT 在工具服务里再查一次，不只在网关查（Sanjay 的审计流；同类写法也出现在企业 RAG 项目里）。
- **结构化输出失败**  
  逐项校验，一条坏结果不丢整次调用（Etcetera）。视觉模型 JSON 不稳定时做字段修复和题型递归（冯威 GLM-4.5V）。多次采样把概率输出收成确定性难度分（蔡杰超）。

## 语音、视觉与多模态

- **语音链路**  
  ASR 回填文案，TTS 时长回填分镜，画面跟音频走（梁慧、冯威）。端侧 Qwen3-ASR + ncnn（邓乾）。实时语音：LiveKit、WebRTC、ElevenLabs、Deepgram（Aman、Yadeesh 的 Faster-Whisper 和 Piper）。Sanjay 的音频 MCP：faster-whisper、VAD、说话人分离、声音事件，发现必须引用时间片。
- **数字人**  
  音色克隆、口型驱动、FFmpeg 合成、GPU 互斥（冯威）。郭靖一侧是数字人视频、热词、名片和渲染引擎连接，后端是 Go，模型多半是对接而不是训练。
- **视觉理解进 Agent**  
  识题、页面和材料 OCR 先变成结构化上下文，再交给 RAG 或生成（王艺辉、冯威、Etcetera 的 PDF 坐标）。Bingo 的缺陷平台：标注、训练、推理、VLM 复核，人在回路，零误放行。
- **三维与空间 Agent**  
  邓乾 ArchAgent：对话改三维场景，React Three Fiber。谷子昂论文是 text-to-3D 和 ReID，和后面的法律 Agent 不是同一条线。

## 和 Agent 绑在一起的工程点

这些不是模型概念，但这批简历用它们解释 Agent 为什么能上线。

- **网关**  
  LiteLLM 统一多家厂商，多 Key、故障转移、限流、长连接（蔡杰超）。按任务槽位路由模型，并给单次运行步数和时长预算（Etcetera、Aman）。
- **异步与一致性**  
  队列、租约选主、幂等扣费或幂等发货（梁慧的支付，蔡杰超的积分三段校验，郭靖的核销并发释放）。SSE 与 WebSocket 分场景：流式 token 用 SSE，多节点控制用 WebSocket（冯威直播助手）。
- **沙盒**  
  代码执行、工具白名单、TTL / LRU、工作区隔离（郭靖、戴雨欣、李鹏斌、Etcetera）。
- **可观测基础**  
  TraceID、W3C traceparent、Prometheus、SLO 和错误预算（梁慧）。日志轮转、通知去重、图缓存失效（戴雨欣）。
- **状态机业务**  
  采购阶段、需求生命周期、题库角色流转、目录方案的确认和 T+3/T+7/T+14 复盘（Etcetera、戴雨欣、蔡杰超）。Agent 建议挂在状态机边上，不替代状态机。
