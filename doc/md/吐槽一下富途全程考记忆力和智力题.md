### 2. Go 语言中，标识符 iota 的拼写是 i-o-t-a，请问这四个字母的 ASCII 码十进制值相加的总和是多少？不许用计算器，心算。

**参考答案**

结论：小写 `iota` 四个字母的 ASCII 十进制之和是 429。

码点是 `i` 105、`o` 111、`t` 116、`a` 97。心算时先减去 100：偏移分别是 5、11、16、-3，相加得 29，再加上 400，得到 429。也可以两两相加：97 + 105 = 202，111 + 116 = 227，202 + 227 = 429。

必须用小写。大写 `IOTA` 是 73 + 79 + 84 + 65 = 301。标识符 `iota` 在语言里是常量生成器，从 0 开始在每个 `const` 声明里逐行加 1；字母码点和这个语义无关。

### 3. 智力题：现在有一杯水，一根绳子，一个气球，你能用几种方法让气球在不用嘴吹的情况下鼓起来？请至少说出三种与编程无关的方法。

**参考答案**

结论：至少有四种物理办法。现场如果只有这三样、又不能加热，能稳定做成的是灌水。

1. 把杯里的水倒进气球，用绳子扎口。液体把气球撑起来，不用嘴，也不用产气。
2. 把这杯水加热，气球口套住杯口，绳子勒在杯沿外面。水蒸气和受热膨胀的空气进入气球。凉水几乎不产蒸汽，所以要热源；杯口还得能被气球口封住。
3. 用气筒、注射器或压缩气瓶往气球里打空气，绳子只负责扎口。
4. 在杯里做产气反应，例如小苏打加醋，或投入干冰。气球套在杯口，绳子固定，生成的气体把气球鼓起。这一方法需要水以外的试剂。

把气球绑在绳子上甩，不能稳定地把空气压进去并留住，不能算一种做法。

### 4. 请准确无误地背诵 Go 语言内置的基本数据类型的零值，并说出 uint8 和 byte 的零值在控制台打印出来时，视觉上有什么区别？

**参考答案**

结论：布尔是 `false`，所有数值类型是 0，字符串是 `""`。`uint8` 和 `byte` 的零值打印出来没有视觉区别。

数值类型包括 `int`、`int8`、`int16`、`int32`、`int64`、`uint`、`uint8`、`uint16`、`uint32`、`uint64`、`uintptr`、`float32`、`float64`。`complex64` 和 `complex128` 的零值是 `0+0i`。`byte` 是 `uint8` 的别名，`rune` 是 `int32` 的别名，零值同样是 0。`uintptr` 也是 0，它的零值不是 `nil`。

`error` 是预声明的接口，零值是 `nil`，不属于上面这组基本类型。指针、切片、映射、通道、函数和接口的零值也是 `nil`。

`byte` 与 `uint8` 是同一个类型。`fmt.Println` 和 `%d`、`%v` 都打印 `0`，`%T` 都打印 `uint8`。用 `%c` 时两者都是 U+0000，控制台上都没有字形。有人以为 `byte` 会按字符打印、`uint8` 会按数字打印；默认格式对这两个类型都是十进制数字。

```go
var u uint8
var b byte
fmt.Println(u, b)           // 0 0
fmt.Printf("%T %T\n", u, b) // uint8 uint8
```

### 5. 概念题：在 Go 语言中，for 循环是一个关键字。如果让你把 for 这个关键字从 Go 语言中彻底删除，但依然要能实现循环功能，你会怎么做？（请从修改编译器或创造新的语法糖角度，描述一个最复杂、最低效的方案）

**参考答案**

结论：循环语义可以留下，生产编译器用条件跳转实现。按题目要求的最复杂、最低效方案，是新增语法糖 `whilst init; cond; post { body }`，再把它降成「每轮一个 goroutine、反射执行语句、用 panic 表示 break 和 continue」。

降级步骤：

1. 从扫描器里删除关键字 `for`。`init`、条件、`post` 和循环体仍按原来的三段语义检查。
2. 循环状态放进堆上的结构体。`init` 在进入前执行一次。
3. 每一轮用 `go` 启动一个新 goroutine。条件闭包和循环体里的每条语句都用 `reflect.Value.Call` 调用。
4. `break` 和 `continue` 各 `panic` 一个本层专用的哨兵值。驱动 goroutine 只 `recover` 这两种哨兵，其他 panic 原样抛出。`continue` 之后仍执行 `post`，`break` 不执行 `post` 并结束。
5. `post` 不直接调用，而是交给 `time.AfterFunc(0, post)`，再用无缓冲 channel 握手，故意多一次调度。
6. 嵌套循环再套一层 goroutine，用 `sync.WaitGroup` 等待。每一层使用不同的哨兵类型，避免内层 `break` 被外层 `recover` 接住。

n 次迭代至少创建 n 个 goroutine，再叠加反射和定时器。`init` 一次、先判断再执行、`post` 在循环体之后，语义可以对齐，常数开销极差。

普通编译器只生成条件跳转。语言里留下的 `goto` 或尾递归也能表达循环。上面这套只用来回答「最复杂、最低效」，面试里要同时说出哨兵必须分层，否则嵌套的 `break` 会跳错层。

### 6. 智力题：有 12 个外观一模一样的小球，其中 1 个重量不同（不知轻重）。给你一架没有砝码的天平，最少称几次能保证找出那个不同的小球，并知道它是轻了还是重了？请描述每一次称量的具体分组方法。

**参考答案**

结论：最少 3 次。2 次只有 3² = 9 种结果，而 12 个球各有偏重、偏轻两种假设，共 24 种，9 覆盖不了 24。3 次有 27 种结果，下面的分组用满 3 次，并能同时判断轻重。

球编号 1 到 12。左重表示左盘下降。

**第一次：1 2 3 4 对 5 6 7 8。**

平，则异常在 9 到 12。**第二次：9 10 11 对 1 2 3**（已知正常）。

- 再平：12 异常。**第三次：12 对 1。** 12 重则 12 偏重，12 轻则 12 偏轻。
- 左重：9、10、11 里有一个偏重。**第三次：9 对 10。** 重者偏重；平则 11 偏重。
- 左轻：9、10、11 里有一个偏轻。**第三次：9 对 10。** 轻者偏轻；平则 11 偏轻。

第一次左重，则 1 到 4 可能偏重，或 5 到 8 可能偏轻。9 到 12 正常。**第二次：1 2 5 对 3 6 9。**

- 左重：1 偏重、2 偏重或 6 偏轻。**第三次：1 对 2。** 重者偏重；平则 6 偏轻。
- 左轻：3 偏重或 5 偏轻。**第三次：3 对 9。** 3 重则 3 偏重；平则 5 偏轻。
- 平：4 偏重、7 偏轻或 8 偏轻。**第三次：7 对 8。** 轻者偏轻；平则 4 偏重。

第一次左轻，嫌疑变成 1 到 4 偏轻，或 5 到 8 偏重。第二次分组不变。

- 第二次左轻：1 偏轻、2 偏轻或 6 偏重。**第三次：1 对 2。** 轻者偏轻；平则 6 偏重。
- 第二次左重：5 偏重或 3 偏轻。**第三次：5 对 9。** 5 重则 5 偏重；平则 3 偏轻。
- 第二次平：4 偏轻、7 偏重或 8 偏重。**第三次：7 对 8。** 重者偏重；平则 4 偏轻。

第一次若不平衡，剩下 8 种假设，后两次要把它们分成每组不超过 3 种。每次称完都要同时得到编号，以及这颗球是偏重还是偏轻。

### 7. 请说出 Go 语言标准库 flag 包中，定义命令行参数类型的函数有哪几个？请按字母倒序背出来。

**参考答案**

结论：定义参数的包级函数按名字字典序从大到小是下面 20 个。`FlagSet` 上有同名方法，顺序相同，包级函数转给 `flag.CommandLine`。

```text
Var
UintVar
Uint64Var
Uint64
Uint
TextVar
StringVar
String
IntVar
Int64Var
Int64
Int
Func
Float64Var
Float64
DurationVar
Duration
BoolVar

```

标准库没有 `Int32`、`Uint32`、`Float32`，也没有不带 `Var` 的 `Text`。`Var` 注册任意 `flag.Value`。`Func` 从 Go 1.16 开始，每次出现都要带值。`TextVar` 从 Go 1.19 开始，目标要实现 `encoding.TextUnmarshaler`，默认值的类型要和它相同并实现 `encoding.TextMarshaler`。`BoolFunc` 从 Go 1.21 开始，可以只写 `-flag`；不带等号时回调收到 `"true"`。

### 8. 请在不查阅资料的情况下，复述 Go 语言官方文档中“Effective Go”章节的任意三段完整段落（中文或英文皆可）。

**参考答案**

结论：这题要的是逐字背诵，原文在官方 Effective Go。复习时把规则讲准即可。面试里直接说背不出原文，再用自己的话讲清下面三节。

格式化。`gofmt` 决定 Go 程序的版式，缩进用 tab，对齐和换行由工具产生。格式是工具的输出，代码评审把时间留给行为。

命名。包名短小写，不用下划线，也不用驼峰。导出标识符用 MixedCaps。只有一个方法的接口常以 `-er` 结尾，例如 `Reader`。取值方法直接用名字，例如 `Owner`；设置方法可以用 `Set`。名字的完整程度随作用域变大。

控制结构。`if`、`for`、`switch` 的条件不加括号，花括号不能省略。`if` 可以带一条初始化语句，变量的作用域覆盖 `if` 和 `else`。语言没有 `while` 和 `do`：只留条件的 `for` 用来表达当条件成立时重复，空的 `for` 是死循环。`switch` 每一支默认结束。`fallthrough` 只用于表达式 `switch`，无条件进入下一支，不再判断下一支的表达式；它不能出现在 type switch 里。

### 9. Go 语言倡导“少即是多”。请你论述一下，在 Go 语言现有的语法中，哪一个标点符号（如分号；、逗号，、点 . 等）是“最多余”的，可以删掉而“几乎不影响”任何功能？并请为你的删除方案想出一个会导致编译失败的、最荒谬的例子。

**参考答案**

结论：对人要敲的字符来说，分号最接近多余；它不能从语言里删掉。逗号和点号删掉之后，参数列表和选择器会大面积失效，谈不上几乎不影响。

Go 在换行处自动插入分号。上一行最后一个记号若是标识符、字面量、`break`、`continue`、`fallthrough`、`return`、`++`、`--`、`)`、`]` 或 `}`，行尾就补一个分号。所以正常换行的语句不用自己写分号。自动插入只发生在行尾，补不出同一行中间的分号。

三段式循环把分号当子句分隔符：

```go
for i := 0; i < 10; i++ {
}
```

删掉分号这个记号后，这段最常见的循环无法编译。

最荒谬的反例是函数体里只剩分号。下面四条空语句今天可以编译；分号一旦不再是记号，文件直接非法。

```go
package main

func main() {
    ;;;;
}
```

逗号分隔参数、实参和复合字面量里的元素，`f(1, 2)` 会立刻失效。点号是选择器 `a.b`，也是浮点字面量的一部分。两者都不满足「几乎不影响」。

### 10. 手写算法：请写一个 Go 函数，它接受一个字符串，然后以“最不优雅”的方式（比如使用最多的 if-else 分支，或最复杂的正则表达式）判断这个字符串是否表示一个有效的 24 小时制时间（如“13:45”）。要求：代码行数尽可能多，逻辑尽可能绕。

**参考答案**

结论：按示例，合法输入恰好是 `HH:MM`，小时 00 到 23，分钟 00 到 59。日常一行是 `time.Parse("15:04", s)`；`"15:04"` 取自参考时间 `Mon Jan 2 15:04:05 MST 2006`。下面按题目要求写分支很多的版本。时间和空间都是 O(1)，输入长度固定为 5，分支再多也不改变复杂度。

`time.Parse` 会拒绝 24 点、60 分和没被布局消费完的多余字符。一位数小时它是否放宽，手写时不要猜，这版明确要求两位。把每个数字再拆成单独的 `if`，行数还能继续增加。

```go
func IsHHMMUgly(s string) bool {
    if s == "" {
        return false
    }
    if len(s) != 5 {
        return false
    }
    if s[2] != ':' {
        return false
    }

    h1, h2 := s[0], s[1]
    m1, m2 := s[3], s[4]

    if h1 == '0' || h1 == '1' {
        if h2 < '0' || h2 > '9' {
            return false
        }
    } else if h1 == '2' {
        if h2 == '0' || h2 == '1' || h2 == '2' || h2 == '3' {
            // 20 到 23
        } else {
            return false
        }
    } else {
        return false
    }

    if m1 == '0' || m1 == '1' || m1 == '2' || m1 == '3' || m1 == '4' || m1 == '5' {
        if m2 == '0' || m2 == '1' || m2 == '2' || m2 == '3' || m2 == '4' ||
            m2 == '5' || m2 == '6' || m2 == '7' || m2 == '8' || m2 == '9' {
            return true
        }
        return false
    }
    return false
}
```

`"13:45"`、`"00:00"`、`"23:59"` 为真。`"24:00"`、`"23:60"`、`"9:45"`、`"13:45:00"` 为假。

### 11. 智力题：你有一桶无限多的红球和蓝球。现在要你蒙上眼睛，从桶里每次拿两个球。如果两个球同色，你就放回一个红球；如果两个球异色，你就放回一个蓝球。桶里最后可能剩下什么颜色的球？这个过程与 Go 的垃圾回收有何“诗意”的关联？

**参考答案**

结论：按有限颗球来做，最后一颗由最初蓝球个数的奇偶决定。蓝球是奇数则最后是蓝，是偶数则最后是红。红球个数不影响。真是无穷多颗时，球数不会降到 1，没有最后一颗。

每次拿走两颗、放回一颗，总数减 1。蓝球数的变化只有三种：两红，蓝球不变；一红一蓝，拿走一个蓝再放回一个蓝，蓝球仍不变；两蓝，蓝球减 2，再放回一个红。三种都保持蓝球奇偶。剩一颗时，蓝球为 1 就是奇数，为 0 就是偶数，所以颜色在开始时已经确定，和抽取顺序无关。

诗意关联只到不变量这一层。Go 的垃圾回收仍是并发、不搬移对象的三色标记-清除，写屏障维持「黑色对象不指向白色对象」。Go 1.26 起默认的 Green Tea 把同一 span 里待扫描的小对象攒起来一起扫，改变的是标记顺序和局部性，可达集合不随扫描顺序改变。蒙眼抽球时，拿球的人不知道过程进行到哪一步，局部规则仍然保住蓝球奇偶；标记和业务 goroutine 交错时，局部涂色规则保住可达性。红和蓝对应不了白、灰、黑。

### 12. 请解释 Go 语言中 ...（省略号）的几种用法。并发明一种全新的、在语法上看似合理但毫无实际用途的 ... 用法。

**参考答案**

结论：语言里的 `...` 只有三处。调用时展开和 `append` 是同一处。

1. 可变参数必须是最后一个参数：`func Sum(xs ...int)`。函数体内它的类型是 `[]int`。调用时不传对应实参，得到的是 nil 切片。
2. 在调用的最后一个实参位置展开切片：`Sum(s...)`。`s` 必须能赋给那个 `[]T`，后面不能再写实参。`append(a, b...)` 用的就是这条规定。
3. 数组复合字面量推断长度：`a := [...]int{1, 2, 3}` 的类型是 `[3]int`。这里的 `...` 表示长度等于元素个数，得到的是数组。`var a [...]int` 不合法，复合字面量里也不能写 `[]int{s...}`。

`func(...T)` 和 `func([]T)` 是两种函数类型，不能互相赋值。返回值列表里不能写 `...`。

发明的用法：允许 `func Log(prefix string, ...)`。最后这个不带类型的 `...` 表示调用处还可以再写实参，这些实参被丢弃，函数体内没有切片，也不能用 `s...` 送进一个有类型的参数。现有的 `...T` 已经能接收并使用这些值，裸 `...` 没有新的表达能力。
