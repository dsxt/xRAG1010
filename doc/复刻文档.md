# 补齐右侧三栏

这份文档是那台电脑需要的全部材料。不要从原来的环境拷贝镜像、源码或配置，不要连接 `10.230` 网段，也不要访问 `zte.com.cn`。构建镜像时只访问公网，下载 Ubuntu 软件包、OpenCode、File Browser 和 Traefik。

Acrec 已经能在这台电脑上打开。左侧录制功能不用重装。右侧「对话」「文件」「桌面」「任务看板」都由本机 WSL 里的容器提供。不使用登录，工号不向任何服务器校验。

本机 WSL2 和 Docker 已经装好。WSL 账号是 `xing`，密码是 `root`。

下面这些域名只写在这台 Windows 的 hosts 里，指向本机 WSL 的 IP。浏览器的请求留在这台电脑上，不会发到外网或原来的内网：

| 界面 | 本机地址 | 容器端口 |
|---|---|---|
| 对话 | `http://{工号}-opencode.acrec.local/L2hvbWUvenRl/session/` | 3000 |
| 文件 | `http://{工号}-files.acrec.local/` | 8888 |
| 桌面 | `http://{工号}-vnc.acrec.local/vnc.html` | 6080 |
| 任务看板 | `http://{工号}-scheduler.acrec.local/` | 8686 |

编辑这台电脑上已有的 `frontend/main_window.py`。不要从别处拷贝这个文件。若里面已经有 `def apply_local_mode`，说明改过了，跳过本节。

```python

```

在这个方法后面增加：

```python

        """LOCAL_MODE 为真时隐藏登录，用工号 LOCAL_USR 直接创建右侧容器。
        不请求任何登录服务器。未开启时返回 False。"""
        config = self.read_config()

            return False
        self.login_button.hide()
        usr = str(config.get('LOCAL_USR', '')).strip()

            self.result_display.append(
                '<span style="color: #f44336;">本地模式未配置 LOCAL_USR（工号），无法创建右侧容器</span>'
            )
            return True
        data = self.read_usr()
        data['USR'] = usr
        self.write_usr(data)
        self.update_login_button()
```

```python
        usr = self.get_current_usr()
```

## 1. 确认 Docker 和 SSH

用 `xing` 打开 Ubuntu。下面命令的密码都是 `root`。

```bash
sudo docker info
```

Acrec 通过 SSH 执行 `sudo docker`。没有 sshd 就补上：

```bash
sudo apt-get update
sudo apt-get install -y openssh-server
sudo systemctl enable --now ssh
```

`systemctl` 不可用时，把下面两行写入 `/etc/wsl.conf`，在 Windows PowerShell 执行 `wsl --shutdown`，重新打开 Ubuntu 后再执行上面的 `systemctl`：

```ini
[boot]
systemd=true
```

建立程序要挂载的目录：

```bash
sudo mkdir -p /home/zte/Downloads/mydocker /home/zte/Documents/WC_opencode
sudo chown -R xing:xing /home/zte
```

查看 WSL 的 IP，后面写入 `REMOTE_HOST`：

```bash
hostname -I
```

在 Windows 里测试，用户名 `xing`，密码 `root`：

```powershell
ssh xing@这里换成WSL的IP
```

Acrec 只连接 22 端口。Windows 自己的 OpenSSH 如果占着 22，不要改 WSL 的端口，`REMOTE_HOST` 填 WSL 的 IP，不要填 `127.0.0.1`。

保存 `scheduler.py`。仓库里没有原来的看板程序，这个页面提供「待办 / 进行中 / 已完成」，数据写在容器里的 `/home/zte/.scheduler/board.json`（也就是宿主机的 `/home/zte/Documents/WC_opencode/{工号}/.scheduler/board.json`）。

```python
#!/usr/bin/env python3
import json
import os
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import urlparse

DATA = "/home/zte/.scheduler/board.json"
COLUMNS = ["待办", "进行中", "已完成"]


def load():
    os.makedirs(os.path.dirname(DATA), exist_ok=True)
    if not os.path.exists(DATA):
        return []
    with open(DATA, "r", encoding="utf-8") as f:
        return json.load(f)


def save(items):
    os.makedirs(os.path.dirname(DATA), exist_ok=True)
    with open(DATA, "w", encoding="utf-8") as f:
        json.dump(items, f, ensure_ascii=False, indent=2)


PAGE = """<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="utf-8">
<title>任务看板</title>
<style>
body { font-family: sans-serif; background:#1e1e1e; color:#eee; margin:0; }
header { padding:16px 20px; background:#2d2d2d; display:flex; gap:8px; }
input { flex:1; padding:8px; border:none; border-radius:4px; }
button { padding:8px 12px; border:none; border-radius:4px; background:#4a90e2; color:#fff; cursor:pointer; }
main { display:flex; gap:12px; padding:16px; }
section { flex:1; background:#2d2d2d; border-radius:8px; padding:12px; min-height:240px; }
.card { background:#3a3a3a; margin:8px 0; padding:8px; border-radius:6px; }
.card button { margin:8px 4px 0 0; background:#555; }
h2 { margin:0 0 8px; font-size:16px; }
</style>
</head>
<body>
<header>
  <input id="title" placeholder="新任务">
  <button onclick="addTask()">添加</button>
</header>
<main id="board"></main>
<script>
const cols = ["待办", "进行中", "已完成"];
async function load() {
  const items = await (await fetch("/api/tasks")).json();
  const board = document.getElementById("board");
  board.innerHTML = "";
  for (const col of cols) {
    const sec = document.createElement("section");
    const heading = document.createElement("h2");
    heading.textContent = col;
    sec.appendChild(heading);
    for (const item of items.filter(function (i) { return i.column === col; })) {
      const card = document.createElement("div");
      card.className = "card";
      const title = document.createElement("div");
      title.textContent = item.title;
      card.appendChild(title);
      for (const target of cols) {
        if (target === col) continue;
        const btn = document.createElement("button");
        btn.textContent = "移到" + target;
        btn.onclick = function () { move(item.id, target); };
        card.appendChild(btn);
      }
      const del = document.createElement("button");
      del.textContent = "删除";
      del.onclick = function () { remove(item.id); };
      card.appendChild(del);
      sec.appendChild(card);
    }
    board.appendChild(sec);
  }
}
async function addTask() {
  const input = document.getElementById("title");
  const title = input.value.trim();
  if (!title) return;
  await fetch("/api/tasks", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({title: title, column: "待办"})
  });
  input.value = "";
  load();
}
async function move(id, column) {
  await fetch("/api/tasks/" + id + "/move", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({column: column})
  });
  load();
}
async function remove(id) {
  await fetch("/api/tasks/" + id + "/delete", {method: "POST"});
  load();
}
load();
</script>
</body>
</html>
"""


class Handler(BaseHTTPRequestHandler):
    def _send(self, code, body, content_type):
        data = body.encode("utf-8") if isinstance(body, str) else body
        self.send_response(code)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def do_GET(self):
        path = urlparse(self.path).path
        if path in ("/", "/index.html"):
            self._send(200, PAGE, "text/html; charset=utf-8")
            return
        if path == "/api/tasks":
            self._send(200, json.dumps(load(), ensure_ascii=False), "application/json; charset=utf-8")
            return
        self._send(404, "not found", "text/plain; charset=utf-8")

    def do_POST(self):
        path = urlparse(self.path).path
        length = int(self.headers.get("Content-Length", "0") or 0)
        raw = self.rfile.read(length) if length else b"{}"
        try:
            payload = json.loads(raw.decode("utf-8") or "{}")
        except Exception:
            self._send(400, "bad json", "text/plain; charset=utf-8")
            return
        items = load()
        parts = path.strip("/").split("/")
        if path == "/api/tasks":
            title = str(payload.get("title", "")).strip()
            column = payload.get("column") or "待办"
            if column not in COLUMNS or not title:
                self._send(400, "bad task", "text/plain; charset=utf-8")
                return
            nid = max((item["id"] for item in items), default=0) + 1
            created = {"id": nid, "title": title, "column": column}
            items.append(created)
            save(items)
            self._send(200, json.dumps(created, ensure_ascii=False), "application/json; charset=utf-8")
            return
        if len(parts) == 4 and parts[0] == "api" and parts[1] == "tasks":
            try:
                tid = int(parts[2])
            except ValueError:
                self._send(404, "not found", "text/plain; charset=utf-8")
                return
            found = next((item for item in items if item["id"] == tid), None)
            if not found:
                self._send(404, "not found", "text/plain; charset=utf-8")
                return
            if parts[3] == "move" and payload.get("column") in COLUMNS:
                found["column"] = payload["column"]
                save(items)
                self._send(200, json.dumps(found, ensure_ascii=False), "application/json; charset=utf-8")
                return
            if parts[3] == "delete":
                save([item for item in items if item["id"] != tid])
                self._send(200, "ok", "text/plain; charset=utf-8")
                return
        self._send(404, "not found", "text/plain; charset=utf-8")

    def log_message(self, fmt, *args):
        return


if __name__ == "__main__":
    ThreadingHTTPServer(("0.0.0.0", 8686), Handler).serve_forever()
```

## 4. 让 Acrec 直接打开三栏

编辑正在运行的 Acrec 旁边的 `rainbow_config.json`（和 `main.py` 或 exe 同一目录）。`LOCAL_USR` 填一个 8 位或 10 位工号，只用于本机容器名和域名，不向任何服务器校验。四个网址后缀保持下面的值：

```json
{
    "LOCAL_MODE": true,
    "LOCAL_USR": "这里换成工号",
    "REMOTE_HOST": "第1步看到的WSL的IP",
    "REMOTE_USER": "xing",
    "REMOTE_PASSWORD": "root",
    "DOCKER_IMAGE": "desktop_vnc:v5",
    "VNC_URL": "-vnc.acrec.local",
    "OPENCODE_URL": "-opencode.acrec.local",
    "NOTEBOOK_URL": "-files.acrec.local",
    "SCHED_URL": "-scheduler.acrec.local"
}
```

用管理员身份启动 Acrec（要写 hosts）。窗口上没有登录按钮。程序会：

1. SSH 到 WSL，创建容器 `opencode{工号}gpt`
2. 把 `/home/zte/Documents/WC_opencode/{工号}` 挂到容器的 `/home/zte`
3. 把四个 `.acrec.local` 域名写进 `C:\Windows\System32\drivers\etc\hosts`，指向 `REMOTE_HOST`

`.acrec.local` 没有公网解析，也不属于原来的内网。hosts 写好之后，这些地址只转到本机 WSL。

右侧「对话」「文件」「桌面」「任务看板」先转圈，对应网页返回后即可打开。

## 常见问题

**启动后没有容器。** 先看 Acrec 窗口里的容器日志。确认第 3 步的 Traefik 在运行，且 `/home/zte/Downloads/mydocker/start.sh` 是可执行文件，不是同名文件夹。然后执行 `sudo docker rm -f opencode工号gpt`，重新启动 Acrec。不要使用登录。

**WSL 的 IP 变了。** `hostname -I` 取值后改 `REMOTE_HOST`。hosts 里已有旧的四行时，程序不会改它们。先删掉这四行，再重新启动 Acrec。

**对话按钮一直转圈，日志里有 `server password`。** 这一版 OpenCode Web 开了密码，程序探测时不带登录信息。在容器里执行 `opencode web --help`，按该版本的说明关掉密码后重启容器。

**80 端口绑定失败。** 在 WSL 里执行 `sudo ss -lptn | grep ':80'`，停掉占用 80 的程序后再启动 Traefik。
